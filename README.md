# MIDI Redactor

Веб-редактор для створення фортепіанних аранжувань під відео та аудіо з експортом у `.mid`.
Вимоги та правила розробки — у [CLAUDE.md](CLAUDE.md), плани задач — у [docs/plans](docs/plans).

## Вимоги

- Python 3.12+ і [uv](https://docs.astral.sh/uv/)
- Node.js 20+ і npm

## Запуск у режимі розробки

```bash
# backend (http://localhost:8000, документація API — /docs)
cd backend
uv sync
uv run uvicorn app.main:app --reload

# frontend (http://localhost:5173), в окремому терміналі
cd frontend
npm install
npm run dev
```

Frontend проксіює запити `/api/*` на backend.

## Тести та перевірки

```bash
cd backend && uv run pytest && uv run ruff check . && uv run ruff format --check . && uv run mypy app
cd frontend && npm test -- --run && npm run lint && npm run typecheck && npm run build
```

Форматування коду:

```bash
cd backend && uv run ruff format .
cd frontend && npm run format
```

## Керування piano roll

- **Додати ноту:** клік по порожньому місцю сітки (нота довжиною в крок сітки); протягування вправо задає тривалість.
- **Перемістити ноту:** перетягнути її по часу й висоті.
- **Змінити тривалість:** потягнути за правий край ноти.
- **Видалити:** правий клік по ноті або `Delete`/`Backspace` для виділеної ноти (фокус на сітці).
- **Скасувати перетягування:** `Escape` до відпускання кнопки миші.
- **Velocity:** поле «Velocity» в інспекторі над сіткою; яскравість ноти відповідає velocity.
- **Сітка:** «Grid» — крок прив'язки, «Snap» — увімкнути/вимкнути прив'язку, «Quantize» — вирівняти виділену ноту, «Zoom in/out» — горизонтальний масштаб.
- **Темп і розмір такту:** поля `♩ =` і розміру в верхній панелі (значення застосовується по Enter або при виході з поля).

Сітка прив'язана до 0 с. Якщо крок не ділить такт націло (наприклад, `1/4 triplet` у 3/4), лінії кроку зсуваються відносно тактів — так само, як і фактичні позиції прив'язки нот.

## Керування педалями

Під сіткою нот є доріжка педалей із трьох рядків: **Sustain** (MIDI CC64), **Sostenuto** (CC66) і **Soft** (CC67). Доріжка прокручується по горизонталі разом із сіткою й лінійкою.

- **Додати натискання:** клік у порожньому місці рядка (інтервал довжиною в долю від початку клітинки сітки); протягування вправо задає кінець. Тип педалі визначає рядок.
- **Перемістити:** перетягнути інтервал по часу. Перенести його в інший рядок не можна: щоб змінити тип, видаліть інтервал і створіть новий.
- **Змінити початок чи кінець:** потягнути за лівий або правий край інтервалу.
- **Сусіди:** інтервали одного типу не перекриваються. Інтервал, який тягнуть на сусідній, зупиняється впритул до нього. Інтервали різних типів можуть перекриватися в часі.
- **Видалити:** правий клік по інтервалу або `Delete`/`Backspace` для виділеного інтервалу (фокус на доріжці).
- **Скасувати перетягування:** `Escape` до відпускання кнопки миші.
- **Виділення:** виділення педалі знімає виділення ноти і навпаки, тому `Delete` видаляє лише те, що підсвічено.
- **«Хвости» нот:** якщо ноту відпущено при натиснутому sustain (або її утримує sostenuto), після ноти видно тонку смугу до моменту, коли звук припиниться.

## Відтворення

- **Play / Pause / Stop** — кнопки в верхній панелі (група «Playback»). Вони керують одночасно нотами, аудіодоріжкою і відео (див. «Синхронізація»). Перше натискання Play (або клавіші) завантажує семпли фортепіано: кнопка показує «Loading piano…», після чого починається відтворення. Stop повертає позицію на початок.
- **Швидкість** від 0.25× до 2× (список «Speed» у верхній панелі) — одна для нот, аудіо й відео.
- **Позиція** показується як `хв:сс.мс · такт.доля`.
- **Старт з довільного місця:** клік по лінійці над сіткою ставить курсор відтворення (playhead). Під час відтворення клік перескакує туди й грає далі.
- **Follow:** коли прапорець увімкнено, piano roll прокручується посторінково за playhead.
- **Віртуальна клавіатура:** натискання клавіші ліворуч від сітки програє ноту, поки кнопку миші тримають.
- **Педалі впливають на звук:** sustain і sostenuto подовжують звучання нот (до кінця «хвоста»), soft робить ноти тихішими (velocity × 0.7).
- Відтворення починається з нот, що стартують у позиції курсора або пізніше; ноти, що почалися раніше, не звучать. Коли відтворення доходить до кінця таймлайну, воно ставиться на паузу, а наступний Play починає з початку.
- Ноти можна редагувати під час відтворення: зміни чути з наступної ноти.

## Синхронізація

Ноти, аудіодоріжка і відео грають на **одному таймлайні** з одним транспортом.

- **Один транспорт.** Play / Pause / Stop і клік по лінійці у верхній панелі запускають, зупиняють і перемотують усе разом. На паузі відео показує кадр, а waveform — курсор у позиції playhead.
- **Спільна швидкість.** «Speed» у верхній панелі змінює темп нот, аудіо й відео разом. Висота тону не змінюється.
- **Перемотування з будь-якої панелі.** Клік по waveform, повзунок відео і кнопки «−5 s» / «+5 s» перемотують весь таймлайн, а не лише свою доріжку. Якщо таймлайн уже пішов далі за кінець коротшого відео, «+5 s» і повзунок у кінці відео таймлайн назад не відкидають.
- **Медіа починається в 0 с таймлайну.** Зсуву медіа немає: вступ без нот просто лишається порожнім у piano roll.
- **Довжина таймлайну** подовжується до кінця найдовшого завантаженого медіа (+2 такти). Після «Remove» таймлайн знову визначають ноти й педалі (щонайменше 60 с).
- **Коротше медіа.** Коли таймлайн доходить до кінця відео чи аудіо, воно зупиняється на останньому кадрі, а ноти й інше медіа грають далі.
- **Корекція розбіжності.** Годинник транспорту (Web Audio) головний. Медіа, що відстає чи випереджає, непомітно підтягується зміною швидкості (до ±5 %), а великий розрив (понад 0.25 с) виправляється перемотуванням.
- **Mute відео** — прапорець «Mute» під відео. Корисно, коли відео й аудіодоріжка — той самий запис, щоб звук не двоївся.
- **Медіа без піаніно не запускається.** Перший Play спершу завантажує семпли фортепіано. Поки вони вантажаться (або після помилки завантаження, до «Retry»), аудіо й відео теж не грають.

## Аудіодоріжка

Панель «Audio track» праворуч унизу.

- **Завантаження:** кнопка «Load audio…» або перетягування файлу на панель. Підтримуються **MP3, WAV, OGG, AAC і M4A (AAC)**. Формат визначається за розширенням, а для файлів без розширення — за MIME-типом.
- **Waveform:** після завантаження з'являється waveform усього файлу. Клік по waveform перемотує весь таймлайн на це місце (і на паузі, і під час відтворення).
- **Відтворення, пауза й швидкість** аудіо керуються спільним транспортом у верхній панелі (Play / Pause / Stop і «Speed», див. «Синхронізація»). Під waveform (група «Audio playback») показується позиція `хв:сс.мс / тривалість`.
- Висота тону на зміненій швидкості не змінюється: браузер сам розтягує звук у часі (`preservesPitch`).
- **Remove** прибирає файл з доріжки.
- **Помилки:** непідтримуваний файл дає повідомлення `Unsupported file …` (уже завантажений файл лишається); формат, який браузер не вміє відтворювати, — `This browser cannot play …`; зіпсований файл — `Could not read …`.
- Файл обробляється лише в браузері (Object URL) і **не завантажується на сервер**.

## Відео

Панель «Video» праворуч угорі.

- **Завантаження:** кнопка «Load video…» або перетягування файлу на панель. Підтримуються **MP4 (`.mp4`, `.m4v`) і WebM (`.webm`)**. Формат визначається за розширенням, а для файлів без розширення — за MIME-типом. `.mov`, `.mkv`, `.avi` поки не приймаються.
- **Відтворення, пауза й швидкість** відео керуються спільним транспортом у верхній панелі (Play / Pause / Stop і «Speed», див. «Синхронізація»). Під відео (група «Video playback») показується позиція `хв:сс.мс / тривалість`.
- **Перемотування:** повзунок під відео (на паузі показує відповідний кадр) і кнопки «−5 s» / «+5 s», які не виходять за межі початку й кінця файлу. Вони перемотують весь таймлайн. Коли повзунок у фокусі, стрілки крокують на 0.1 с.
- **Mute** вимикає звук відео; налаштування зберігається для наступних файлів.
- Висота тону звуку відео на зміненій швидкості не змінюється (`preservesPitch`).
- **Remove** прибирає відео з панелі.
- **Помилки:** непідтримуваний файл дає повідомлення `Unsupported file …` (уже завантажене відео лишається); формат, який браузер не вміє відтворювати, — `This browser cannot play …`; зіпсований файл або непідтримуваний кодек — `Could not play …`.
- Файл обробляється лише в браузері (Object URL) і **не завантажується на сервер**.

## Звук

Для відтворення використовуються семпли **Salamander Grand Piano** (автор Alexander Holm, ліцензія [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/)) у вигляді зменшеного набору mp3 від Tone.js (30 файлів, по одному на кожні три півтони). Файли лежать у репозиторії, у `frontend/public/samples/salamander/`, тож звук працює без доступу до мережі. Атрибуція й перелік змін — у `frontend/public/samples/salamander/README.md`.

Щоб відтворити набір файлів з першоджерела (зафіксований коміт `Tonejs/audio`), виконайте:

```bash
cd frontend && npm run fetch-samples
```

## Структура

- `backend/` — FastAPI-застосунок (`app/main.py`), роутери в `app/api/`, схеми в `app/models/`, логіка в `app/services/`, тести в `tests/`.
  Перевірка зв'язку: `GET /api/health` → `{"status": "ok"}`.
- `frontend/` — React + TypeScript (Vite). Тести Vitest лежать поруч із кодом (`*.test.tsx`).
